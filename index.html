Brief Watcher

Muse researches a local business and writes a brief. A launchd agent picks it up and opens an interactive Claude Code session in Ghostty that builds the pitch site to 60%.

Pipeline

  1. Muse writes the briefIt creates ~/Projects/freelance/<camelCase>/ and puts brief.md directly inside it. That file is the only one Muse writes.
  2. launchd wakes the watcherIt runs brief-watcher.sh when a folder is added to ~/Projects/freelance, every 5 minutes, and at login.
  3. The watcher checks each briefIt skips any folder that has a .claude-claimed marker, and any brief changed in the last 60 seconds (Muse may still be writing it).
  4. A Ghostty tab opensThrough Ghostty's AppleScript, it opens a new tab in that folder and types claude "/pitch-site …" into the login shell. No flags are passed, so the session uses the usual settings.
  5. The folder is claimedThe watcher writes .claude-claimed and shows a macOS notification.
  6. The pitch-site skill buildsThe session builds the site unattended to 60%, writes HANDOFF.md, and pushes to a private repo.
  7. The build marks itself doneThe skill writes .pitch-site-done (an ISO timestamp and the repo URL) and posts a "60% build pushed" notification.

Files in a prospect folder

FileWritten byMeaning
brief.mdMuseThe build contract. BRIEF.md also works. Nobody else may delete, rename or rewrite it.
.claude-claimedWatcherClaude has picked this folder up. Delete it to trigger a rebuild.
HANDOFF.mdpitch-siteAssumptions, gaps and open questions for the last 40%.
.pitch-site-donepitch-siteBuild pushed. Line 1 is a timestamp and line 2 is the repo URL.

Rules for Muse

  • Write the brief in one go. The build starts once the brief has been unchanged for 60 seconds, and later edits won't reach it. Safest: write brief.md.tmp, then mv it to brief.md.
  • Don't write a TRIGGER.md. The skill already covers what it said.
  • Never touch .claude-claimed.
  • Leave the folder alone after handoff. The build session owns it from then on.

Operating it

# start
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.ellie.brief-watcher.plist
# stop
launchctl bootout gui/$(id -u)/com.ellie.brief-watcher
# log
tail -f ~/Library/Logs/brief-watcher.log
# rebuild one prospect
rm ~/Projects/freelance/<prospect>/.claude-claimed

The first run asks macOS for permission to control Ghostty (Automation). Approve it once.

Source

brief-watcher.sh is the watcher. com.ellie.brief-watcher.plist is the launchd agent; copy it to ~/Library/LaunchAgents/. The script is symlinked from ~/.local/bin/brief-watcher.sh.
